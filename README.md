# TechEra AI Market & Reel Engine (v0.1.0)

স্বয়ংক্রিয় মার্কেট রিসার্চ, ভবিষ্যৎ চাহিদা পূর্বাভাস (Future Forecast), স্ব-শিক্ষণ মেমরি (Self-Learning Memory), মাল্টি-ক্লিপ কপিরাইট-সেফ রিলস এডিটর এবং মোবাইল ওয়েব অ্যাপ (PWA)।

## ফোল্ডার কাঠামো (`D:\TechEra_AI_Reel_Engine_v0.1`):
- `config/version.json` — লাইভ ভার্সন কন্ট্রোল (`v0.1.0` -> `v0.2.0` -> `v1.0.0`)
- `config/niches.json` — টেক গ্যাজেট, ফ্যাশন/উইন্টার, হোম/কিচেন, মোবাইল/অডিও ও ভাইরাল নিশ নলেজ বেস
- `modules/trend_scout.py` — ডেইলি ট্রেন্ডিং প্রোডাক্ট ভিডিও রিসার্চার ও র‍্যাংকিং ইঞ্জিন
- `modules/future_forecaster.py` — আগামী ৩০–৬০ দিনের চাহিদা ও নেক্সট-জেন কন্টেন্ট পূর্বাভাস
- `modules/memory_learner.py` — স্ব-শিক্ষণ পারফরম্যান্স মেমরি ও ডুপ্লিকেট প্রোটেকশন
- `modules/reel_studio.py` — মাল্টি-ভিডিও হাইলাইট ক্লিপিং, HD শার্পনেস এনহ্যান্সার ও কপিরাইট-সেফ রেন্ডারার
- `docs/index.html` — ইনস্টলেবল মোবাইল অ্যাপ (PWA) ড্যাশবোর্ড
- `.github/workflows/ai_reel_engine.yml` — GitHub Actions ক্লাউড অটোমেশন
